# 드림핵 Addition calculator

- 날짜: 2026-11-12
- 플랫폼: 드림핵 (Dreamhack) 워게임
- 난이도: 실버 3 (체감은 실버 3치고 훨씬 쉬운 느낌)
- 분야: 웹, Python `eval()` 인젝션
- 공격 방법: 코드를 보고 브라우저 입력창으로 공격, 입력값은 파이썬 코드로 생성
- 결과: 플래그 획득 (`DH{...}`, 공개 저장소라 가림)
- 익스플로잇 코드: [261112_dreamhack_addition-calculator.py](261112_dreamhack_addition-calculator.py)

## 문제 구조

- Flask 앱이 POST로 받은 `formula`를 `filter()`로 검사한 뒤 `eval(formula)`을 실행한다.
- `eval()` 결과가 그대로 페이지에 출력된다 (`result=formula`).
- `filter()`가 `True`를 돌려주면 `Filtered`가 출력된다.
  - 금지어: `system`, `curl`, `flag`, `subprocess`, `popen` (`re.I`라 대소문자 무시)
  - 허용 글자: 영문 대소문자, 숫자, 공백, `.`, `(`, `)`, `+`
  - 따옴표(`'`, `"`)를 쓸 수 없어서 문자열을 직접 적을 수 없다.

## 취약점 원리

필터는 입력한 글자만 검사하고, `eval()` 안에서 실행 중에 만들어지는 값은 검사하지 않는다. 그래서 `chr()`로 숫자를 글자로 바꿔 이어 붙이면, 따옴표나 `flag`를 입력에 쓰지 않고도 원하는 문자열을 만들 수 있다.

## 풀이 과정과 시행착오

1. `filter()`의 `re.search()`가 걸리면 `True`가 되는 게 이상하다고 생각했다. 함수가 `True`를 돌려주면 "막아라"는 뜻이라는 것을 확인했다.
2. `eval()`, `string.digits`가 무엇인지 확인했다. `eval("ls")`처럼 셸 명령은 바로 실행되지 않는다는 것도 확인했다.
3. 필터 코드를 보고 따옴표(`'`)가 막힌 게 가장 컸다. `eval()`로 돌아가는 명령어가 뭐가 있을지 생각하고 구글링하다가 `open()`을 알게 됐다.
4. 식 전체 `open('flag.txt', 'r').read()`를 한 글자씩 `f"str({ord(i)})"`로 바꿔 우회하려 했다. 그런데 `str(111)`은 `'o'`가 아니라 `'111'`이라 `chr()`로 바꿨다.
5. 식 전체를 `chr()`로 만들어 보냈더니 `open('flag.txt', 'r').read()`가 문자열로 그대로 출력됐다. `open().read()`는 실행되어야 하니 `chr()`로 바꾸는 범위에서 빼야 한다는 걸 생각하지 못했다.
6. 필터에 걸리는 파일 이름만 `chr()`로 만들기로 했다. 처음에는 `chr(39)`(작은따옴표)를 앞뒤에 붙였다. `chr()`로 만든 값은 이미 문자열이라, 따옴표를 붙이면 따옴표까지 파일 이름에 들어가서 빼야 한다는 것을 확인했다.
7. `flag.txt`만 `chr()`로 만들어 `open(...).read()`에 넣는 코드를 짜서 입력값을 얻었다. 출력 끝에 남는 `+`는 직접 지우고 브라우저 입력창에 넣어 플래그를 얻었다.

최종 입력:

```
open(chr(102)+chr(108)+chr(97)+chr(103)+chr(46)+chr(116)+chr(120)+chr(116)).read()
```
